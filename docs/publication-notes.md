# Publication and accuracy notes

This repository is based on an academic report. It may not contain all original code, machine images, configuration files, or logs.

Before publishing additional materials:
- Review **all pages and screenshots** for student identifiers, passwords, personal email addresses, secrets, tokens and private keys.
- Although a password might belong to a disposable lab, do not publish it if reused anywhere else; rotate if necessary.
- Check course publication restrictions and rights to third-party material.
- Do not upload a working ransomware binary or claim the test used real Lynx malware.
- Label any reconstructed code as reconstructed, and test it independently before presenting it as functional.
- Keep evidence and conclusion claims specific to the documented lab observations.

A full project report, if published, should be clearly labelled as a historical **lab report**, with any lab-only credentials identified or redacted as appropriate.
